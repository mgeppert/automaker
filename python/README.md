# Python port of Automaker

This directory contains the Python port of the Automaker server and shared libraries. The React UI in `../apps/ui/` is kept as-is and will talk to this Python backend over HTTP + WebSocket.

- **Scope:** web-only, must run on Windows and Linux. No Electron desktop build.
- **Rules:** see `../PORT_RULES.md` at the repo root for the durable rules governing the port.
- **Status:** skeleton. No implementation yet.
